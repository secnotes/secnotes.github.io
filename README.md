# secnotes.github.io

一名网络安全研究者的个人安全笔记站点，托管于 GitHub Pages。

站点内容涵盖：

- **威胁情报** — 安全情报收集与整理
- **在线工具** — 安全工具（在线反汇编/汇编、加解密、密码字典、Radare2 等）与生活工具（高考、个税、万年历、天气、旅行等）
- **贡献项目** — 开源参与
- **维护工具** — 日常工作流
- **AI 评价** — 使用反馈

## 特性

- 中英文双语切换
- 明暗主题切换
- 响应式布局，适配移动端

## 技术栈

纯静态站点，无构建步骤：单个 `index.html` + 内联 CSS/JS，开箱即用。

## 本地预览

直接用浏览器打开 `index.html`，或启动一个本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
