# 图片目录 | Images Folder

请将你的高清风景图片放在这个目录中。

## 支持的格式
- JPG / JPEG
- PNG
- WebP
- GIF

## 使用方法

1. 将你的风景图片复制到此目录
2. 打开 `index.html` 文件
3. 在 `<script>` 部分找到 `imageFiles` 数组
4. 将数组中的文件名改为你实际的图片文件名

例如：
```javascript
const imageFiles = [
    'my-photo-1.jpg',
    'my-photo-2.jpg',
    'my-photo-3.jpg',
    'my-photo-4.jpg'
];
```

## 推荐图片尺寸
- 最小宽度：1920px
- 推荐：1920x1080 或更高
- 文件大小：建议每张图片 < 2MB
